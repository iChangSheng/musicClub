## ✨网页实现功能
1. 左上角音频播放器，支持循环播放背景音乐
2. 页面顶部锚点导航：社团简介 | 活动安排 | 风采展示 | 社员故事 | 在线报名；各板块支持返回顶部
3. 活动安排：实现跨行跨列HTML表格（2026春季学期活动表）
4. 风采板块：图片点击跳转子页面，其余图片展示；视频支持全屏放大观看
5. 在线报名：完整表单，全部控件放在table表格内
6. **样式效果**
- 标题黑体加粗，正文宋体；段落首行缩进2字符，行间距1.4
- 文字、图片、视频自适应浏览器窗口大小，窗口缩放自动变化
- 图片与短片容器左右同等留白
- CSS动态渐变音符装饰背景，不使用图片资源
7. 两个页面互相跳转：主页 ↔ club_intro.html
